# VitaAI 智慧医院系统接口文档

**文档版本**: v1.0  
**更新日期**: 2026-05-19  
**基础URL**: `http://localhost:8080`  

---

## 1. 接口概述

### 1.1 基本信息

| 项目 | 说明 |
|------|------|
| 协议 | HTTP |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 认证方式 | JWT Bearer Token |
| 分页参数 | page（页码，从1开始）、pageSize（每页条数） |

### 1.2 统一响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": "2026-05-19T10:00:00"
}
```

分页响应：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "content": [],
    "totalElements": 100,
    "totalPages": 5,
    "number": 1,
    "size": 20
  }
}
```

## 2. 认证接口 — `/api/auth`

### 2.1 用户注册
```
POST /api/auth/register
```
**请求体**:
```json
{
  "username": "testuser",
  "email": "test@qq.com",
  "password": "123456",
  "confirmPassword": "123456",
  "captchaCode": "123456",
  "role": "USER",
  "realName": "张三"
}
```
**响应**:
```json
{
  "code": 200,
  "message": "注册成功",
  "data": { "id": 1, "username": "testuser" }
}
```

### 2.2 用户登录
```
POST /api/auth/login
```
**请求体**:
```json
{
  "account": "admin",
  "password": "admin123"
}
```
**响应**:
```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "accessToken": "eyJ...",
    "refreshToken": "eyJ...",
    "tokenType": "Bearer",
    "expiresIn": 7200,
    "user": { "id": 1, "username": "admin", "email": "admin@vitaai.com", "role": "ADMIN" }
  }
}
```

### 2.3 刷新 Token
```
POST /api/auth/refresh
Authorization: Bearer {refreshToken}
```

### 2.4 用户登出
```
POST /api/auth/logout
Authorization: Bearer {accessToken}
```

## 3. AI 诊断接口 — `/api/ai`

### 3.1 发送诊断消息
```
POST /api/ai/chat
Authorization: Bearer {token}
```
**请求体**:
```json
{
  "message": "我头痛三天了，伴有发热",
  "conversationId": "uuid（首次对话不传）",
  "healthRecordId": null
}
```

### 3.2 流式对话 (SSE)
```
POST /api/ai/chat/stream
Authorization: Bearer {token}
Content-Type: application/json
```
SSE 事件类型: `connected` → `chunk`（多次）→ `done`

### 3.3 诊断历史
```
GET /api/ai/diagnoses?page=1&pageSize=10
GET /api/ai/diagnoses/{id}
DELETE /api/ai/diagnoses/{id}
Authorization: Bearer {token}
```

### 3.4 诊断反馈
```
POST /api/ai/diagnoses/{id}/feedback
Authorization: Bearer {token}
```
**请求体**:
```json
{
  "accuracy": "ACCURATE",
  "comments": "诊断准确"
}
```
accuracy 可选值: `ACCURATE` / `PARTIALLY_ACCURATE` / `INACCURATE`

### 3.5 诊断报告
```
POST /api/ai/diagnoses/{id}/report
Authorization: Bearer {token}
```

### 3.6 Skills 管理
```
GET    /api/ai/skills                  # Skills 列表
POST   /api/ai/skills                  # 新增 Skill
PUT    /api/ai/skills/{id}             # 更新 Skill
DELETE /api/ai/skills/{id}             # 删除 Skill
POST   /api/ai/skills/upload           # 上传 Skill 文件 ({ name, content })
POST   /api/ai/skills/sync             # 从 Vita-skills 目录同步
Authorization: Bearer {admin token}
```

## 4. 管理员接口 — `/api/admin`

### 4.1 仪表盘
```
GET /api/admin/stats
```
返回用户/医生/疾病/药品/诊断/待审核数量。

### 4.2 用户管理
```
GET /api/admin/users?page=1&pageSize=10&role=USER
PUT /api/admin/users/{id}
```
**更新请求体**:
```json
{ "role": "DOCTOR", "isDisabled": false }
```

### 4.3 内容审核
```
GET  /api/admin/content/pending
PUT  /api/admin/content/diseases/{id}/review
PUT  /api/admin/content/drugs/{id}/review
```
**审核请求体**:
```json
{ "status": "APPROVED", "rejectReason": "" }
```

### 4.4 疾病药品 CRUD
```
GET    /api/admin/diseases?keyword=&status=&page=1&pageSize=10
POST   /api/admin/diseases
PUT    /api/admin/diseases/{id}
DELETE /api/admin/diseases/{id}

GET    /api/admin/drugs?keyword=&status=&page=1&pageSize=10
POST   /api/admin/drugs
PUT    /api/admin/drugs/{id}
DELETE /api/admin/drugs/{id}
```
管理员新增/编辑的内容直接 APPROVED。

### 4.5 审计日志
```
GET /api/admin/audit-logs?page=1&pageSize=20
```

## 5. 医生接口 — `/api/doctor`

```
GET  /api/doctor/stats                    # 仪表盘统计
GET  /api/doctor/patients                 # 患者列表
GET  /api/doctor/diagnoses                # 诊断记录
GET  /api/doctor/diseases                 # 疾病列表
POST /api/doctor/diseases                 # 新增疾病建议 → PENDING
PUT  /api/doctor/diseases/{id}            # 修改疾病建议 → PENDING
GET  /api/doctor/drugs                   # 药品列表
POST /api/doctor/drugs                   # 新增药品建议 → PENDING
PUT  /api/doctor/drugs/{id}              # 修改药品建议 → PENDING
Authorization: Bearer {doctor token}
```

## 6. 在线问诊接口 — `/api/messages`

```
GET    /api/messages                      # 留言列表

PUT    /api/messages/{id}                 # 编辑留言

PUT    /api/messages/{id}/status          # 切换状态

```

```
GET /api/drugs?keyword=&page=1&pageSize=20
GET /api/drugs/{id}
```

### 7.3 用户接口 — `/api/users`
```
GET /api/users/profile                   # 查看个人资料
PUT /api/users/profile                   # 更新个人资料
PUT /api/users/password                  # 修改密码
Authorization: Bearer {token}
```

### 7.4 健康档案 — `/api/health-records`
```
GET /api/health-records                  # 查看健康档案
PUT /api/health-records                  # 创建/更新健康档案
Authorization: Bearer {token}
```

### 7.5 收藏夹 — `/api/favorites`
```
GET    /api/favorites?type=DISEASE       # 收藏列表 (type: DISEASE/DRUG)
POST   /api/favorites                    # 添加收藏 ({ targetId, targetType })
DELETE /api/favorites/{id}               # 取消收藏
Authorization: Bearer {token}
```

### 7.6 症状自测 — `/api/symptoms`
```
GET /api/symptoms/categories             # 症状分类列表
GET /api/symptoms/assessments            # 自测记录
POST /api/symptoms/assessments           # 提交自测
Authorization: Bearer {token}
```

### 7.7 联系留言 — `/api/contact`
```
GET  /api/contact                        # 留言列表
POST /api/contact                        # 提交留言 ({ name, phone, email, content })
```

### 7.8 反馈 — `/api/review`
```
POST /api/review/feedback                # 提交反馈 ({ type, content, contact })
GET  /api/review/feedback                # 查看反馈列表 (admin)
Authorization: Bearer {token}
```

### 7.9 系统接口 — `/api/system`
```
GET /api/system/info                     # 系统信息
GET /api/system/stats                    # 公开统计数据
```

## 8. 错误码说明

| HTTP Status | code | 说明 |
|-------------|------|------|
| 200 | 200 | 操作成功 |
| 400 | 400 | 参数校验失败 |
| 401 | 401 | 未认证或 Token 过期 |
| 403 | 403 | 权限不足 |
| 404 | 404 | 资源不存在 |
| 500 | 500 | 服务器内部错误 |
