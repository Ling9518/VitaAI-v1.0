## 1. 接口概述

### 1.1 基本信息

| 项目 | 说明 |
|------|------|
| 协议 | HTTPS |
| 数据格式 | JSON |
| 字符编码 | UTF-8 |
| 版本控制 | URL路径版本化 |
| 分页方式 | limit/offset 或 page/pageSize |

### 1.2 请求格式

```
HTTP Method: GET/POST/PUT/DELETE
Content-Type: application/json
Accept: application/json
Authorization: Bearer {token}
```

### 1.3 响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": "2026-05-13T10:00:00Z",
  "requestId": "uuid-string"
}
```

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "list": [],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 100,
      "totalPages": 5
    }
  },
  "timestamp": "2026-05-13T10:00:00Z"
}
```

## 2. 认证说明

### 2.1 认证方式

系统采用JWT（JSON Web Token）进行身份认证。

### 2.2 Token获取

1. 用户登录成功后，系统返回access_token和refresh_token
2. access_token有效期为2小时
3. refresh_token有效期为7天
4. Token过期后，使用refresh_token刷新

### 2.3 Token使用

```
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 2.4 权限说明

| 角色 | 权限说明 |
|------|----------|
| VISITOR | 仅可访问公开接口 |
| USER | 可访问用户相关接口 |
| DOCTOR | 可访问医生相关接口 |
| ADMIN | 可访问所有接口 |

## 3. 通用说明

### 3.1 日期时间格式

- 请求参数：ISO 8601格式 `YYYY-MM-DDTHH:mm:ssZ`
- 或简化格式：`YYYY-MM-DD HH:mm:ss`
- 日期参数：`YYYY-MM-DD`

### 3.2 文件上传

- 最大文件大小：10MB
- 支持格式：JPG、PNG、PDF
- 上传接口：POST /upload

### 3.3 频率限制

| 接口类型 | 限制 |
|----------|------|
| 登录接口 | 5次/分钟 |
| 普通API | 100次/分钟 |
| AI诊断接口 | 10次/分钟 |
| 上传接口 | 10次/小时 |

## 4. 认证接口

### 4.1 用户注册

```
POST /auth/register
```

**请求参数：**

```json
{
  "username": "string",      // 用户名，6-20位字母数字
  "email": "string",         // 邮箱地址
  "password": "string",      // 密码，8-20位
  "confirmPassword": "string", // 确认密码
  "role": "USER|DOCTOR",    // 角色类型
  "realName": "string",      // 真实姓名（医生必填）
  "doctorLicense": "string",  // 医生执照号（医生必填）
  "captchaToken": "string"   // 验证码Token
}
```

**响应示例：**

```json
{
  "code": 200,
  "message": "注册成功，请查收验证邮件",
  "data": {
    "userId": 12345,
    "username": "user123",
    "email": "user@example.com",
    "role": "USER",
    "emailVerified": false
  }
}
```

### 4.2 用户登录

```
POST /auth/login
```

**请求参数：**

```json
{
  "account": "string",       // 用户名或邮箱
  "password": "string",      // 密码
  "captchaToken": "string"  // 验证码Token（可选）
}
```

**响应示例：**

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "accessToken": "eyJhbGciOiJIUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJIUzI1NiIs...",
    "expiresIn": 7200,
    "tokenType": "Bearer",
    "user": {
      "id": 12345,
      "username": "user123",
      "email": "user@example.com",
      "role": "USER",
      "avatarUrl": "https://..."
    }
  }
}
```

### 4.3 刷新Token

```
POST /auth/refresh
```

**请求参数：**

```json
{
  "refreshToken": "string"   // 刷新Token
}
```

### 4.4 用户登出

```
POST /auth/logout
```

**请求参数：**

```json
{
  "refreshToken": "string"   // 需要失效的refreshToken
}
```

### 4.5 邮箱验证

```
POST /auth/verify-email
```

**请求参数：**

```json
{
  "token": "string"   // 邮箱验证Token
}
```

### 4.6 发送验证码

```
POST /auth/captcha/send
```

**请求参数：**

```json
{
  "email": "string",   // 邮箱地址
  "type": "REGISTER|LOGIN|PASSWORD_RESET"  // 验证码类型
}
```

### 4.7 忘记密码

```
POST /auth/password/forgot
```

**请求参数：**

```json
{
  "email": "string"   // 注册邮箱
}
```

### 4.8 重置密码

```
POST /auth/password/reset
```

**请求参数：**

```json
{
  "token": "string",       // 重置Token
  "newPassword": "string",  // 新密码
  "confirmPassword": "string"  // 确认密码
}
```


## 15. 错误码说明

### 15.1 错误码表

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| 200 | 操作成功 | - |
| 400 | 请求参数错误 | 检查请求参数格式 |
| 401 | 未授权 | 请先登录 |
| 403 | 禁止访问 | 无权限访问该资源 |
| 404 | 资源不存在 | 检查资源ID是否正确 |
| 405 | 请求方法不支持 | 检查HTTP方法 |
| 409 | 资源冲突 | 资源已存在或状态冲突 |
| 410 | 资源已删除 | 资源已被删除 |
| 422 | 参数验证失败 | 检查参数是否符合要求 |
| 429 | 请求过于频繁 | 请稍后再试 |
| 500 | 服务器内部错误 | 联系技术支持 |
| 502 | 网关错误 | 服务暂时不可用 |
| 503 | 服务不可用 | 服务维护中 |
| 504 | 网关超时 | 服务响应超时 |

### 15.2 业务错误码

| 错误码 | 说明 | 处理建议 |
|--------|------|----------|
| A001 | 用户名已存在 | 请使用其他用户名 |
| A002 | 邮箱已注册 | 请使用其他邮箱或找回密码 |
| A003 | 验证码错误 | 请重新获取验证码 |
| A004 | 验证码已过期 | 请重新获取验证码 |
| A005 | 原密码错误 | 请输入正确的原密码 |

| H001 | 健康档案已存在 | 每位用户仅能创建一个档案 |
| D001 | 对话记录不存在 | 检查对话ID是否正确 |

| C001 | 内容已存在 | 请检查内容是否重复提交 |
