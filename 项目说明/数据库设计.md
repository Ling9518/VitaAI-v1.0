# VitaAI 智慧医院系统数据库设计文档

**文档版本**: v1.0  
**更新日期**: 2026-05-19  
**数据库**: MySQL 8.0 (InnoDB, utf8mb4)

---

## 1. 数据库概述

### 1.1 基本信息

| 项目 | 说明 |
|------|------|
| 数据库名 | smart_hospital |
| 字符集 | utf8mb4 / utf8mb4_unicode_ci |
| 存储引擎 | InnoDB |
| ORM 框架 | Spring Data JPA + Hibernate |
| DDL 策略 | update（开发）/ validate（生产） |
| 缓存 | Redis 7.0（Token 缓存、会话管理） |

### 1.2 表清单

| 序号 | 表名 | 说明 | 主要关联 |
|------|------|------|----------|
| 1 | users | 用户表 | - |
| 2 | health_records | 健康档案表 | users.id |
| 3 | diseases | 疾病表 | users.id (created_by, reviewed_by) |
| 4 | drugs | 药品表 | users.id (created_by, reviewed_by) |
| 5 | skills | AI技能表 | users.id (created_by) |
| 6 | diagnosis_records | 诊断记录表 | users.id, health_records.id |
| 7 | ai_conversations | AI对话记录表 | diagnosis_records.id, users.id |
| 8 | messages | 在线问诊留言表 | users.id |
| 9 | contact_messages | 联系留言表 | - |
| 10 | user_favorites | 用户收藏表 | users.id |
| 11 | symptom_categories | 症状分类表 | - |
| 12 | symptom_assessments | 症状自测表 | users.id |
| 13 | feedback | 用户反馈表 | users.id |
| 14 | content_reviews | 内容审核表 | users.id |
| 15 | audit_logs | 操作审计日志表 | users.id |
| 16 | email_verifications | 邮箱验证码表 | - |
| 17 | disease_drug_rel | 疾病药品关联表 | diseases.id, drugs.id |
| 18 | disease_skill_rel | 疾病技能关联表 | diseases.id, skills.id |
| 19 | patient_doctor_rel | 患者医生关联表 | users.id |

## 2. 核心表设计

### 2.1 用户表 (users)

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| email | VARCHAR(100) | UNIQUE, NOT NULL | 邮箱 |
| password | VARCHAR(255) | NOT NULL | BCrypt 哈希 |
| role | ENUM('VISITOR','USER','DOCTOR','ADMIN') | NOT NULL | 角色 |
| real_name | VARCHAR(100) | - | 真实姓名 |
| phone | VARCHAR(20) | - | 手机号 |
| gender | ENUM('MALE','FEMALE','UNKNOWN') | - | 性别 |
| birthday | DATE | - | 生日 |
| avatar_url | VARCHAR(500) | - | 头像URL |
| doctor_license | VARCHAR(100) | - | 医生执照号 |
| doctor_dept | VARCHAR(50) | - | 医生科室 |
| doctor_title | VARCHAR(50) | - | 医生职称 |
| is_verified | BOOLEAN | DEFAULT FALSE | 邮箱已验证 |
| is_disabled | BOOLEAN | DEFAULT FALSE | 是否禁用 |
| last_login_at | DATETIME | - | 最后登录 |
| login_attempts | INT | DEFAULT 0 | 登录失败次数 |
| locked_until | DATETIME | - | 锁定截止时间 |
| created_at | DATETIME | NOT NULL | 创建时间 |
| updated_at | DATETIME | NOT NULL | 更新时间 |

### 2.2 疾病表 (diseases)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |
| name | VARCHAR(200) | 疾病名称 |
| alias | VARCHAR(200) | 别名 |
| icd_code | VARCHAR(20) | ICD编码 |
| cause | TEXT | 病因 |
| symptoms | TEXT | 症状 |
| diagnosis | TEXT | 诊断方法 |
| treatment | TEXT | 治疗方案 |
| prevention | TEXT | 预防措施 |
| complications | TEXT | 并发症 |
| classification | VARCHAR(100) | 分类 |
| body_system | VARCHAR(50) | 身体系统 |
| severity | ENUM('MILD','MODERATE','SEVERE') | 严重程度 |
| is_infectious | BOOLEAN | 是否传染 |
| is_chronic | BOOLEAN | 是否慢性 |
| views_count | INT | 浏览量 |
| favorites_count | INT | 收藏数 |
| status | ENUM('PENDING','APPROVED','REJECTED') | 审核状态 |
| reject_reason | VARCHAR(500) | 拒绝原因 |
| created_by | BIGINT FK→users.id | 创建者 |
| reviewed_by | BIGINT FK→users.id | 审核者 |
| reviewed_at | DATETIME | 审核时间 |
| published_at | DATETIME | 发布时间 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 2.3 药品表 (drugs)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT PK | 主键 |

## 4. Redis 缓存设计

| Key 模式 | 类型 | TTL | 说明 |
|----------|------|-----|------|
| `token:access:{userId}` | String | 2h | accessToken |
| `token:refresh:{userId}` | String | 7d | refreshToken |
| `token:blacklist:{token}` | String | 至过期 | 登出黑名单 |
| `verification:{email}` | Hash | 5min | 邮箱验证码 |

## 5. 数据库安全

| 措施 | 说明 |
|------|------|
| 密码存储 | BCrypt 哈希，不可逆 |
| 敏感配置 | 环境变量 `.env`（Git 忽略） |
| 操作审计 | audit_logs 表全量记录用户操作 |
| SQL 注入防护 | Spring Data JPA 参数化查询 |
| 连接加密 | HikariCP 连接池，useSSL=false（内网） |
| 字符集 | utf8mb4，支持 emoji 和特殊字符 |
