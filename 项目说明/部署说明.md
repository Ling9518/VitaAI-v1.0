## 1. 部署概述

### 1.1 部署架构

```
┌─────────────────────────────────────────────────────────┐
│                   用户浏览器                              │
│              http://localhost:80 (生产)                   │
│              http://localhost:5173 (开发)                 │
└────────────────────────┬────────────────────────────────┘
                         │
┌────────────────────────┴────────────────────────────────┐
│              Frontend (Nginx + Vue 3 静态文件)            │
│                    Port: 80                              │
└────────────────────────┬────────────────────────────────┘
                         │ API 请求 /api/*
                         │
┌────────────────────────┴────────────────────────────────┐
│            Backend (Spring Boot 3.2.5 Monolith)          │
│                    Port: 8080                            │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │  Auth    │ │ Disease  │ │  Drug    │ │ Message  │  │
│  │ Service  │ │ Service  │ │ Service  │ │ Service  │  │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘  │

│  │   AI     │ │ Health   │ │ Review   │ │  Audit   │  │
│  │ Service  │ │ Record   │ │ Service  │ │   Log    │  │
```

|------|------|------|

| vitaai-frontend | 自构建 (Nginx + Vue) | 80 |

## 3. 本地开发部署

### 3.1 前置准备

确保 MySQL 和 Redis 服务已启动，并手动创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS smart_hospital
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

### 3.2 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 填入真实凭据（数据库密码、JWT密钥、AI API Key、邮箱配置）
```

### 3.3 启动后端

```bash
cd backend
mvn clean compile
mvn spring-boot:run
# 运行在 http://localhost:8080
```

### 3.4 启动前端

```bash
cd frontend
npm install
npm run dev
# 运行在 http://localhost:5173
```

前端开发服务器已配置代理，`/api/*` 请求会自动转发到 `http://localhost:8080`。

### 3.5 初始化数据库

首次启动后，可通过后端自动 DDL（`ddl-auto: update`）创建表结构，或手动导入：

```bash
mysql -uroot -p smart_hospital < database/schema.sql
mysql -uroot -p smart_hospital < database/seed.sql
```

## 4. Docker Compose 部署

### 4.1 项目结构

```
VitaAI-v1.0/
├── docker-compose.yml              # Docker 编排文件
├── .env                            # 环境变量（gitignore）
├── .env.example                    # 环境变量模板
├── backend/                        # 后端源码
├── frontend/                       # 前端源码
├── database/
│   ├── schema.sql                  # 建表脚本（容器首次启动自动执行）
│   └── seed.sql                    # 种子数据
└── docker/app/
    ├── Dockerfile.backend          # 后端镜像
    └── Dockerfile.frontend         # 前端镜像
```

### 4.2 docker-compose.yml

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: vitaai-mysql
    restart: unless-stopped
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD:?required}
      MYSQL_DATABASE: smart_hospital
      MYSQL_CHARSET: utf8mb4
      MYSQL_COLLATION: utf8mb4_unicode_ci
      TZ: Asia/Shanghai
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
      - ./database/schema.sql:/docker-entrypoint-initdb.d/01-schema.sql
      - ./database/seed.sql:/docker-entrypoint-initdb.d/02-seed.sql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      timeout: 20s
      retries: 10
    networks:
      - vitaai-network

  redis:
    image: redis:7-alpine
    container_name: vitaai-redis
    restart: unless-stopped
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    command: redis-server --appendonly yes
    healthcheck:
      test: ["CMD", "redis-cli", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5
    networks:
      - vitaai-network

  backend:
    build:
      context: ./backend
      dockerfile: ../docker/app/Dockerfile.backend
    container_name: vitaai-backend
    restart: unless-stopped
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/smart_hospital?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: ${MYSQL_ROOT_PASSWORD:?required}
      SPRING_REDIS_HOST: redis
      SPRING_REDIS_PORT: 6379
      JWT_SECRET: ${JWT_SECRET:?required}
      AI_API_KEY: ${AI_API_KEY:?required}
      AI_BASE_URL: ${AI_BASE_URL:-https://api.deepseek.com/anthropic}
      AI_MODEL: ${AI_MODEL:-deepseek-v4-flash}
      MAIL_HOST: ${MAIL_HOST:-smtp.qq.com}
      MAIL_PORT: ${MAIL_PORT:-587}
      MAIL_USERNAME: ${MAIL_USERNAME:-}
      MAIL_PASSWORD: ${MAIL_PASSWORD:-}
      TZ: Asia/Shanghai
    ports:
      - "8080:8080"
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_healthy
    networks:
      - vitaai-network

  frontend:
    build:
      context: ./frontend
      dockerfile: ../docker/app/Dockerfile.frontend
    container_name: vitaai-frontend
    restart: unless-stopped
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - vitaai-network

volumes:
  mysql_data:
  redis_data:

networks:
  vitaai-network:
    driver: bridge
```

### 4.3 Dockerfile（后端）

```dockerfile
# Build stage
FROM maven:3.9-eclipse-temurin-17-alpine AS builder
WORKDIR /build
COPY pom.xml .
RUN mvn dependency:go-offline -B 2>/dev/null || true
COPY src ./src
RUN mvn clean package -DskipTests -q

# Runtime stage
FROM eclipse-temurin:17-jre-alpine
WORKDIR /app
COPY --from=builder /build/target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "-Dspring.profiles.active=docker", "app.jar"]
```

### 4.4 Dockerfile（前端）

```dockerfile
FROM node:20-alpine AS builder
WORKDIR /app
COPY package.json package-lock.json* ./
RUN npm install
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY ../nginx/nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### 4.5 启动与停止

```bash
# 1. 配置环境变量
cp .env.example .env
# 编辑 .env 填入真实凭据

# 2. 启动所有服务
docker-compose up -d

# 3. 查看服务状态
docker-compose ps

# 4. 查看日志
docker-compose logs -f backend
docker-compose logs -f frontend

# 5. 停止服务
docker-compose down

# 6. 停止并删除数据卷（慎用）
docker-compose down -v
```

## 5. 环境变量配置

所有敏感配置通过 `.env` 文件管理，模板见 `.env.example`：

```bash
# 数据库
MYSQL_ROOT_PASSWORD=your_db_password

# JWT 密钥（256位 Base64）
JWT_SECRET=your-256-bit-base64-secret

# AI 服务 (DeepSeek Anthropic API)
AI_API_KEY=sk-your-api-key
AI_BASE_URL=https://api.deepseek.com/anthropic
AI_MODEL=deepseek-v4-flash

# 邮件（QQ邮箱 SMTP）
MAIL_HOST=smtp.qq.com
MAIL_PORT=587
MAIL_USERNAME=your_email@qq.com
MAIL_PASSWORD=your_smtp_authorization_code
```

注意事项：
- `.env` 文件已加入 `.gitignore`，不会提交到 Git
- Docker Compose 中必填变量使用 `${VAR:?required}` 语法，缺失时会报错
- 本地开发时，后端通过 `spring-dotenv` 读取 `.env` 文件

## 6. 数据库初始化

### 6.1 自动初始化

Docker Compose 首次启动时，MySQL 容器会自动执行 `database/` 目录下的 SQL 文件：

- `01-schema.sql` — 建表脚本（19 张表 + 3 张关联表）
- `02-seed.sql` — 种子数据（管理员账号、示例疾病、示例药品）

### 6.2 手动初始化

```bash
# 进入 MySQL 容器
docker-compose exec mysql mysql -uroot -p smart_hospital

# 或从宿主机导入
mysql -h127.0.0.1 -uroot -p smart_hospital < database/schema.sql
mysql -h127.0.0.1 -uroot -p smart_hospital < database/seed.sql
```

## 7. 运维管理

### 7.1 日志查看

```bash
# 查看后端日志
docker-compose logs -f backend

# 查看前端 Nginx 日志
docker-compose logs -f frontend

# 查看 MySQL 日志
docker-compose logs -f mysql

# 查看最近 100 行
docker-compose logs --tail=100 backend
```

### 7.2 数据备份

```bash
# 备份 MySQL 数据库
docker-compose exec mysql mysqldump -uroot -p smart_hospital | gzip > backup_$(date +%Y%m%d).sql.gz

# 恢复
gunzip < backup_20260519.sql.gz | docker-compose exec -T mysql mysql -uroot -p smart_hospital
```

### 7.3 容器重启策略

所有容器均配置 `restart: unless-stopped`：
- 服务异常退出 → 自动重启
- 宿主机重启 → 自动启动
- 手动 `docker stop` → 不自动重启

### 7.4 健康检查

| 容器 | 检查方式 | 间隔 |
|------|----------|------|
| MySQL | `mysqladmin ping` | 10s |
| Redis | `redis-cli ping` | 10s |
| Backend | depends_on MySQL + Redis healthy | — |

## 8. 故障排查

### 8.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 后端启动失败 | `.env` 未配置或缺少必填变量 | 检查 `.env` 文件，确保所有必填变量已设置 |
| 数据库连接失败 | MySQL 未就绪或密码错误 | 等待 MySQL 健康检查通过，验证 `MYSQL_ROOT_PASSWORD` |
| AI 诊断返回空 | API Key 无效或额度耗尽 | 检查 `AI_API_KEY` 和 API 余额 |
| 前端页面空白 | 前端构建失败或 Nginx 配置错误 | 查看 `docker-compose logs frontend` |
| 端口冲突 | 3306/6379/8080/80 已被占用 | 停止本地服务或修改 `docker-compose.yml` 端口映射 |
| 邮件发送失败 | SMTP 配置错误 | 检查 `MAIL_USERNAME` 和 `MAIL_PASSWORD`（QQ 邮箱需授权码） |

### 8.2 常用排查命令

```bash
# 检查容器状态
docker-compose ps

# 进入后端容器
docker-compose exec backend sh

# 测试 MySQL 连接
docker-compose exec mysql mysql -uroot -p -e "SELECT 1;"

# 测试 Redis 连接
docker-compose exec redis redis-cli PING

# 查看后端应用健康状态
curl http://localhost:8080/api/system/info

# 查看容器资源占用
docker stats
```
