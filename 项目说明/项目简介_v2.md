# 智慧医院系统 / Smart Hospital System

## 项目简介 / Project Introduction

智慧医院系统是一个基于人工智能和大数据技术的医疗辅助平台，旨在为学校、工厂、监狱等不方便前往医院的人群提供便捷、安全的医疗服务。系统整合了医生诊断案例，将其转化为"skills"并植入主流大模型中，实现精准的病情判断。

Smart Hospital System is an AI-powered medical assistance platform that provides convenient and secure medical services for people in schools, factories, prisons, and other locations where access to hospitals is limited. The system integrates doctor diagnostic cases into "skills" and embeds them into mainstream large language models for accurate disease diagnosis.

## 项目特点 / Key Features

- **人工智能诊断**: 整合医生诊断案例为"skills"，通过大模型实现精准病情判断
- **多角色支持**: 支持游客、用户、管理员、医生四种角色
- **智能医生助手**: 支持多轮对话、历史诊断记录、诊断报告生成
- **健康档案管理**: 用户可建立个人健康档案，记录病史、过敏史、用药记录
- **症状自测工具**: 提供结构化症状选择问卷，引导用户准确描述病情
- **完整医疗管理**: 疾病管理、药品管理、最新科研成果管理
- **数据安全保障**: 数据脱敏、操作审计、合规认证、隐私计算
- **验证机制**: 邮箱验证码注册，医生执业信息验证

- **AI Diagnosis**: Integrates doctor diagnostic cases as "skills" for accurate disease diagnosis through large language models
- **Multi-role Support**: Supports four roles: visitor, user, administrator, and doctor
- **Smart Doctor Assistant**: Supports multi-round dialogue, historical diagnosis records, diagnostic report generation
- **Health Records Management**: Users can establish personal health records, tracking medical history, allergies, and medications
- **Symptom Self-assessment Tool**: Provides structured symptom selection questionnaires to guide users in accurately describing conditions
- **Complete Medical Management**: Disease management, drug management, latest research results management
- **Data Security**: Data desensitization, operation audit, compliance certification, privacy computing
- **Verification Mechanism**: Email verification code registration, doctor practice information verification

## 数据库设计 / Database Design

### 主要数据表 / Main Tables

#### 用户表 (users)
```sql
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    role ENUM('VISITOR', 'USER', 'DOCTOR', 'ADMIN') DEFAULT 'VISITOR',
    real_name VARCHAR(100),
    phone VARCHAR(20),
    avatar_url VARCHAR(500),
    doctor_license VARCHAR(100),
    is_verified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 健康档案表 (health_records)
```sql
CREATE TABLE health_records (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    medical_history TEXT,
    allergy_history TEXT,
    medication_records TEXT,
    family_history TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 疾病表 (diseases)
```sql
CREATE TABLE diseases (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL,
    cause TEXT,
    symptoms TEXT,
    classification VARCHAR(100),
    views_count INT DEFAULT 0,
    created_by BIGINT,
    status ENUM('PENDING', 'APPROVED', 'REJECTED') DEFAULT 'PENDING',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (created_by) REFERENCES users(id)
);
```

#### 药品表 (drugs)
```sql
CREATE TABLE drugs (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL,
    search_keywords TEXT,
    efficacy TEXT,
    usage_dosage TEXT,
    drug_type VARCHAR(100),
    views_count INT DEFAULT 0,
    created_by BIGINT,
    status ENUM('PENDING', 'APPROVED', 'REJECTED') DEFAULT 'PENDING',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (created_by) REFERENCES users(id)
);
```

#### 技能表 (skills)
```sql
CREATE TABLE skills (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(200) NOT NULL,
    content TEXT NOT NULL,
    category VARCHAR(100),
    ai_model VARCHAR(100),
    created_by BIGINT,
    usage_count INT DEFAULT 0,
    accuracy_rate DECIMAL(5,2),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (created_by) REFERENCES users(id)
);
```

#### 诊断记录表 (diagnosis_records)
```sql
CREATE TABLE diagnosis_records (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    conversation_id VARCHAR(100),
    symptoms TEXT,
    diagnosis_result TEXT,
    suggested_diseases TEXT,
    suggested_drugs TEXT,
    severity_level ENUM('LOW', 'MEDIUM', 'HIGH', 'CRITICAL'),
    report_url VARCHAR(500),
    feedback_accuracy ENUM('ACCURATE', 'INACCURATE', 'PENDING') DEFAULT 'PENDING',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 用户收藏表 (user_favorites)
```sql
CREATE TABLE user_favorites (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    item_type ENUM('DISEASE', 'DRUG', 'ARTICLE') NOT NULL,
    item_id BIGINT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

#### 操作审计日志表 (audit_logs)
```sql
CREATE TABLE audit_logs (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT,
    operation_type VARCHAR(100) NOT NULL,
    operation_desc TEXT,
    ip_address VARCHAR(50),
    user_agent TEXT,
    request_data TEXT,
    response_data TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## API文档 / API Documentation

### 认证接口 / Authentication API
- `POST /api/auth/register` - 用户注册
- `POST /api/auth/login` - 用户登录
- `POST /api/auth/refresh` - 刷新token
- `POST /api/auth/logout` - 用户登出
- `POST /api/auth/verify-email` - 邮箱验证

### 用户接口 / User API
- `GET /api/users/profile` - 获取用户资料
- `PUT /api/users/profile` - 更新用户资料
- `PUT /api/users/password` - 修改密码

### 健康档案接口 / Health Records API
- `GET /api/health-records` - 获取健康档案
- `POST /api/health-records` - 创建健康档案
- `PUT /api/health-records` - 更新健康档案

### 症状自测接口 / Symptom Assessment API
- `GET /api/symptoms/categories` - 获取症状分类
- `POST /api/symptoms/assess` - 提交症状自测
- `GET /api/symptoms/assess/{id}` - 获取自测结果

### 用户收藏接口 / User Favorites API
- `GET /api/favorites` - 获取收藏列表
- `POST /api/favorites` - 添加收藏
- `DELETE /api/favorites/{id}` - 取消收藏

### 疾病接口 / Disease API
- `GET /api/diseases` - 获取疾病列表（支持Elasticsearch搜索）
- `GET /api/diseases/{id}` - 获取疾病详情
- `POST /api/diseases` - 创建疾病
- `PUT /api/diseases/{id}` - 更新疾病
- `DELETE /api/diseases/{id}` - 删除疾病

### 药品接口 / Drug API
- `GET /api/drugs` - 获取药品列表（支持Elasticsearch搜索）
- `GET /api/drugs/{id}` - 获取药品详情
- `POST /api/drugs` - 创建药品
- `PUT /api/drugs/{id}` - 更新药品
- `DELETE /api/drugs/{id}` - 删除药品

### 智能医生接口 / AI Doctor API
- `POST /api/ai/chat` - 与智能医生多轮对话
- `POST /api/ai/chat/stream` - 流式对话
- `GET /api/ai/history` - 获取历史诊断记录
- `GET /api/ai/history/{id}` - 获取单条诊断详情
- `POST /api/ai/report` - 生成诊断报告
- `GET /api/ai/report/{id}` - 下载诊断报告
- `POST /api/ai/feedback` - 提交诊断反馈
- `POST /api/ai/image-diagnosis` - 图片识别诊断
- `GET /api/ai/skills` - 获取技能列表
- `POST /api/ai/skills` - 添加技能
- `PUT /api/ai/skills/{id}` - 更新技能
- `DELETE /api/ai/skills/{id}` - 删除技能

### 医生统计接口 / Doctor Statistics API
- `GET /api/doctor/stats` - 获取诊疗统计数据
- `GET /api/doctor/stats/diagnosis` - 诊断量统计
- `GET /api/doctor/stats/satisfaction` - 患者满意度统计
- `GET /api/doctor/stats/accuracy` - 诊断准确率统计

### 内容审核接口 / Content Review API
- `GET /api/review/pending` - 获取待审核内容列表
- `POST /api/review/{id}/approve` - 审核通过
- `POST /api/review/{id}/reject` - 审核拒绝

### Docker部署 / Docker Deployment
```yaml
# docker-compose.yml
version: '3.8'

services:
  mysql-master:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: smart_hospital
    ports:
      - "3306:3306"
    volumes:
      - mysql_master_data:/var/lib/mysql

  mysql-slave:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: smart_hospital
    ports:
      - "3307:3306"
    volumes:
      - mysql_slave_data:/var/lib/mysql

  elasticsearch:
    image: elasticsearch:8.11.0
    environment:
      - discovery.type=single-node
      - xpack.security.enabled=false
    ports:
      - "9200:9200"
    volumes:
      - es_data:/usr/share/elasticsearch/data

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  backend:
    build: ./backend
    ports:
      - "8080:8080"
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql-master:3306/smart_hospital
      SPRING_ELASTICSEARCH_URIS: http://elasticsearch:9200
      SPRING_REDIS_HOST: redis
    depends_on:
      - mysql-master
      - elasticsearch
      - redis

  frontend:
    build: ./frontend
    ports:
      - "80:80"
    depends_on:
      - backend

volumes:
  mysql_master_data:
  mysql_slave_data:
  es_data:
```
