# VitaAI 智慧医院系统 - 项目简介

**版本**: v1.0.0 | **更新日期**: 2026-05-19

## 项目简介

VitaAI 是一个基于人工智能的医疗辅助平台，旨在为学校、工厂、监狱等不便前往医院的人群提供便捷、安全的医疗服务。系统整合医生诊断案例，将其转化为"Skills"并植入大模型中，实现精准的病情判断。

VitaAI is an AI-powered medical assistance platform that provides convenient and secure medical services for people in schools, factories, prisons, and other locations where access to hospitals is limited. The system integrates doctor diagnostic cases into "Skills" and embeds them into large language models for accurate disease diagnosis.

## 项目特点

- **人工智能诊断**: 基于 DeepSeek V4 Flash 大模型，整合 Vita-skills 医学知识库，支持多轮对话、SSE 流式响应与结构化诊断报告
- **多角色支持**: 游客、用户、医生、管理员四种角色，各有专属工作台
- **健康档案管理**: 个人健康档案，记录病史、过敏史、用药记录
- **在线问诊系统**: 用户留言 → 医生回复/编辑/撤回 → 状态标记 → 管理员可编辑双方内容
- **疾病/药品管理**: 管理员 CRUD，医生提交建议（待审核），含内容审核流程
- **数据安全保障**: JWT 认证（双 Token 机制）、BCrypt 密码哈希、操作审计日志、角色权限控制
- **症状自测**: 结构化症状问卷，引导准确描述病情

## 功能模块

### 1. 游客功能
- 浏览系统主页、热门疾病、常用药品
- 搜索疾病/药品、查看详情（统计浏览量）
- 注册成为系统用户（邮箱验证码）
- 使用"联系我们"留言

### 2. 普通用户功能
- **个人中心**: 修改个人资料（姓名、性别、生日、手机号、头像）、修改密码
- **健康档案**: 建立个人健康档案（病史、过敏史、用药记录、家族病史）
- **AI智能诊断**: 多轮对话诊断、查看历史诊断记录、生成诊断报告、诊断反馈
- **在线问诊**: 给医生留言咨询，查看自己的留言及医生回复，编辑/删除自己的留言
- **用户收藏**: 收藏疾病和药品
- **症状自测**: 结构化问卷症状评估

### 3. 医生功能
- **仪表盘统计**: 患者数、诊断数、待审核数
- **患者列表**: 查看患者信息、查看健康档案和诊断记录
- **诊断记录**: 查看所有诊断记录详情
- **在线问诊**: 查看用户留言、回复/编辑回复/撤回回复、标记状态
- **疾病反馈**: 新增/修改疾病建议（提交后待管理员审核）
- **药品反馈**: 新增/修改药品建议（提交后待管理员审核）
- **AI智能诊断**: 使用 AI 辅助诊断

### 4. 管理员功能
- **仪表盘统计**: 用户/医生/疾病/药品/诊断/待审核数量
- **用户管理**: 查看所有用户、按角色筛选、启用/禁用、修改角色
- **内容审核**: 审核医生提交的疾病和药品（APPROVED/REJECTED）
- **疾病管理**: 完整 CRUD（直接 APPROVED）
- **药品管理**: 完整 CRUD（直接 APPROVED）
- **在线问诊管理**: 查看所有留言和回复、编辑双方内容
- **Skills 管理**: Skills CRUD、文件上传、从 Vita-skills 目录同步
- **审计日志**: 查看全量操作审计日志

## 内容审核工作流

```
医生提交新增/修改 → 状态: PENDING
                        ↓
            管理员审核:
            ├── APPROVED（对外可见）
            └── REJECTED（含拒绝原因）

管理员直接操作 → 直接 APPROVED
```

## 技术栈

### 后端
- **Java 17**
- **Spring Boot 3.2.5**
- **Spring Security + JWT**（双 Token：accessToken 2h + refreshToken 7d）
- **Spring Data JPA + Hibernate**
- **MySQL 8.0**（主数据库）
- **Redis 7.0**（Token 缓存与会话管理）
- **Spring Boot Mail**（QQ邮箱 SMTP）
- **Maven**（构建管理）

### 前端
- **Vue 3.x**（Composition API + `<script setup>`）
- **TypeScript**
- **Vue Router**（含权限路由守卫）
- **Pinia**（状态管理）
- **Element Plus**（UI 组件库）
- **Axios**（HTTP 客户端，JWT 拦截器）
- **ECharts**（图表可视化）
- **Vite**（构建工具）

### AI 集成
- **DeepSeek V4 Flash** — 通过 Anthropic 兼容 API 调用
- **Vita-skills** — Markdown 文件系统存储的诊断知识库，支持同步到数据库
- **SSE 流式响应** — 前端实时显示 AI 回复

### 安全
- **环境变量管理敏感配置**（`.env` 文件，Git 忽略）
- **JWT 双 Token 机制**
- **BCrypt 密码哈希**
- **操作审计日志**（AuditLog 全量追溯）
- **角色权限控制**（VISITOR / USER / DOCTOR / ADMIN）

## 快速开始

### 环境要求
- JDK 17+ / Node.js 18+ / MySQL 8.0+ / Redis 6.0+ / Maven 3.8+

### 后端启动
```bash
cd backend
cp ../.env.example ../.env   # 编辑 .env 填入真实凭据
mvn clean compile
mvn spring-boot:run          # http://localhost:8080
```

### 前端启动
```bash
cd frontend
npm install
npm run dev                  # http://localhost:5173
```
