# 智慧医院系统 / Smart Hospital System

**版本**: v3.0 | **更新日期**: 2026-05-14

## 项目简介 / Project Introduction

智慧医院系统（VitaAI）是一个基于人工智能和大数据技术的医疗辅助平台，旨在为学校、工厂、监狱等不便前往医院的人群提供便捷、安全的医疗服务。系统整合了医生诊断案例，将其转化为"Skills"并植入主流大模型中，实现精准的病情判断。

VitaAI is an AI-powered medical assistance platform that provides convenient and secure medical services for people in schools, factories, prisons, and other locations where access to hospitals is limited. The system integrates doctor diagnostic cases into "Skills" and embeds them into mainstream large language models for accurate disease diagnosis.

## 项目特点 / Key Features

- **人工智能诊断**: 整合医生诊断案例为"Skills"，通过大模型实现精准病情判断，支持多轮对话与结构化诊断报告
- **多角色支持**: 支持游客、普通用户、医生、管理员四种角色，各有专属工作台
- **智能医生助手**: 支持多轮对话、历史诊断记录查看、诊断报告生成、AI辅助医生回复
- **健康档案管理**: 用户可建立个人健康档案，记录病史、过敏史、用药记录、家族病史
- **在线问诊系统**: 用户留言咨询 → 医生回复/编辑/撤回 → 标记解决状态 → 管理员可编辑双方内容
- **疾病/药品管理**: 管理员全权管理（增删改查），医生可提交新增/修改建议（待审核）
- **内容审核流程**: 医生提交内容为 PENDING 状态 → 管理员审核 APPROVED/REJECTED
- **数据安全保障**: JWT认证、操作审计日志、角色权限控制
- **验证机制**: 邮箱验证码注册，医生执业信息验证

- **AI Diagnosis**: Integrates doctor diagnostic cases as "Skills" for accurate disease diagnosis through large language models, with multi-round dialogue and structured reports
- **Multi-role Support**: Visitor, User, Doctor, Administrator — each with dedicated dashboards
- **Smart Doctor Assistant**: Multi-round dialogue, diagnosis history, diagnostic reports, AI-assisted doctor replies
- **Health Records Management**: Personal health profiles with medical history, allergies, medications, family history
- **Online Consultation System**: User messages → Doctor replies/edit/withdraw → Status toggle (unresolved/resolved) → Admin can edit both sides
- **Disease/Drug Management**: Admin full CRUD control; doctors submit new items & edit suggestions (pending review)
- **Content Review Workflow**: Doctor submissions = PENDING → Admin review = APPROVED/REJECTED
- **Data Security**: JWT authentication, operation audit logs, role-based access control
- **Verification Mechanism**: Email verification for registration, doctor license verification

- **Homepage**: Browse homepage, search diseases/drugs, view details (with view tracking)

- **AI Smart Diagnosis**: Multi-round diagnostic chat, history, structured reports, feedback

### 3. 管理员功能 / Administrator Functions

- **Dashboard Stats**: Total users, doctors, diseases, drugs, diagnoses, pending reviews

- **Content Review**: Review doctor-submitted diseases & drugs (APPROVED/REJECTED with reason)
- **Disease Management**: Full CRUD — create, edit (preserves status), delete diseases
- **Drug Management**: Full CRUD — create, edit (preserves status), delete drugs
- **Online Consultation Management**: View all messages & replies, admin can edit both user messages and doctor replies

- **Drug Feedback**: View drug list, submit new drug suggestions (pending admin review), submit edit suggestions (pending admin review)
- **AI Smart Diagnosis**: Multi-round dialogue with AI doctor

## 内容审核工作流 / Content Review Workflow

```
医生提交新增/修改 → 状态: PENDING (待审核)
                          ↓
              管理员审核:
              ├── APPROVED (已审核，对外可见)
              └── REJECTED (已拒绝，含拒绝原因)
```

- **医生提交**: 疾病/药品的新增和修改建议，自动设为 PENDING 状态
- **管理员直接操作**: 管理员新增/编辑的疾病/药品直接为 APPROVED 状态
- **医生界面**: "疾病反馈"和"药品反馈"两个独立标签页，每行有"修改建议"按钮

## 在线问诊工作流 / Online Consultation Workflow

```
用户提交留言 → 医生查看 → 医生回复（可多次编辑）
                           ├── 撤回回复
                           ├── 标记已解决/未解决
                           └── AI辅助诊断（跳转诊断页面）

管理员权限:
├── 编辑用户留言内容
├── 编辑医生回复内容
└── 撤回医生回复
```

## 技术栈 / Technology Stack

### 后端 / Backend
- **Java 21**
- **Spring Boot 3.2.5**
- **Spring Security + JWT** (认证授权，BCrypt密码加密)
- **Spring Data JPA + Hibernate** (数据访问)
- **MySQL 8.0** (主数据库)
- **Redis** (Token缓存与黑名单)
- **Maven** (构建管理)

### 前端 / Frontend
- **Vue 3.x** (Composition API + `<script setup>`)
- **TypeScript**
- **Vue Router** (路由管理)
- **Element Plus** (UI组件库)
- **Axios** (HTTP客户端，JWT拦截器)
- **Vite** (构建工具)

### AI集成 / AI Integration
- **DeepSeek (astron-code-latest)** — 通过 Spark 代理调用
- **Skills 库管理** (文件系统存储，支持上传和同步)
- **Vita-skills** — 医生诊断案例转化的结构化诊断知识库

### 数据与安全 / Data & Security
- **MySQL + JPA/Hibernate ORM**
- **Redis** (Token管理)
- **JWT双Token机制** (accessToken 2h + refreshToken 7d)
- **BCrypt密码哈希**
- **操作审计日志** (AuditLog全量追溯)
- **角色权限控制** (VISITOR / USER / DOCTOR / ADMIN)

## 快速开始 / Quick Start

### 环境要求 / Prerequisites
- JDK 17+
- Node.js 18+
- MySQL 8.0+
- Redis 6.0+
- Maven 3.8+

### 后端启动 / Backend Setup
```bash
cd backend

# 配置数据库 (修改 src/main/resources/application.yml)
# spring.datasource.url=jdbc:mysql://localhost:3306/vitaai
# spring.datasource.username=root
# spring.datasource.password=your_password

# 编译运行
mvn clean compile
mvn spring-boot:run
# 后端运行在 http://localhost:8080
```

### 前端启动 / Frontend Setup
```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
# 前端运行在 http://localhost:5173
```
