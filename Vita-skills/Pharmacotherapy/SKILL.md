# 药物治疗技能 (Pharmacotherapy Skill)

## 概述

本技能提供全面的药物治疗辅助功能，涵盖120+种药物分类、90+种疾病的药物治疗方案。通过分析疾病类型、患者特征，提供个体化药物治疗建议。

**数据来源：**
- Medscape Drug Reference
- UpToDate Drug Information
- 中国药典
- 临床药物治疗学指南

## 核心能力

- **药物选择**：基于疾病提供一线、二线药物推荐
- **剂量方案**：提供常用剂量、给药途径、频次
- **作用机制**：解释药物作用机理和药理特点
- **禁忌识别**：识别用药禁忌和注意事项
- **相互作用**：检测药物相互作用风险
- **不良反应**：提示常见和严重不良反应
- **特殊人群**：肝肾功能不全、妊娠哺乳等调整

## 工作流程

### 步骤1：明确治疗需求

当用户请求药物治疗建议时，明确：

- **目标疾病**：需要治疗的疾病名称或ICD编码
- **患者特征**：年龄、体重、肝肾功能、合并症
- **用药史**：当前用药、过敏史
- **治疗目标**：急性期治疗/维持治疗/预防

### 步骤2：检索药物方案

从 `data/drug-database.json` 检索相关药物治疗方案：

```json
{
  "疾病名称": "高血压",
  "ICD-11": "BA00",
  "一线药物": [
    {"药物": "氨氯地平", "剂量": "5-10mg/日", "分类": "CCB"},
    {"药物": "缬沙坦", "剂量": "80-320mg/日", "分类": "ARB"}
  ],
  "二线药物": [
    {"药物": "氢氯噻嗪", "剂量": "12.5-25mg/日", "分类": "利尿剂"}
  ],
  "药物分类": ["CCB", "ARB", "ACEI", "利尿剂", "β受体阻滞剂"],
  "作用机制": "...",
  "禁忌症": "...",
  "注意事项": "..."
}
```

### 步骤3：个体化调整

根据患者特征进行剂量调整：

| 特殊情况 | 调整原则 |
|---------|---------|
| 肝功能不全 | 根据Child-Pugh分级减量或禁用 |
| 肾功能不全 | 根据eGFR调整剂量或换药 |
| 老年患者 | 从小剂量起始，缓慢加量 |
| 妊娠期 | 评估FDA妊娠分级，选择安全药物 |
| 儿童患者 | 按体重/体表面积计算剂量 |

## 特殊人群用药指南

### 妊娠期用药分级（FDA）

| 分级 | 含义 | 示例药物 |
|-----|------|---------|
| A | 安全 | 左甲状腺素、叶酸 |
| B | 相对安全 | 二甲双胍、青霉素类 |
| C | 权衡利弊 | 大多数新药 |
| D | 有害但必要时可用 | ACEI、ARB（禁用） |
| X | 禁用 | 华法林、甲氨蝶呤 |

### 肝功能不全剂量调整

```python
# Child-Pugh分级
A级(5-6分): 正常剂量
B级(7-9分): 减量50%或延长给药间隔
C级(≥10分): 禁用或严重减量

# 需调整药物示例
- 他汀类: 严重肝病减量
- β受体阻滞剂: 肝硬化慎用
- NOAC: 严重肝病禁用
```

### 肾功能不全剂量调整

```python
# eGFR调整原则
eGFR ≥ 60: 正常剂量
eGFR 30-59: 部分药物需减量
eGFR 15-29: 多数药物需减量
eGFR < 15: 严重调整或禁用

# 示例
- 二甲双胍: eGFR<30禁用
- NOAC: 根据eGFR调整剂量
- 万古霉素: 根据eGFR调整剂量和间隔
```

## 使用示例

### 示例1：高血压药物治疗

**用户输入：**
> 55岁男性，新诊断高血压，血压155/95mmHg，无合并症，肾功能正常。请推荐药物治疗方案。

**输出：**
```markdown
## 高血压药物治疗建议

### 一线治疗选择
| 药物名称 | 起始剂量 | 目标剂量 | 给药频次 | 药物分类 |
|---------|---------|---------|---------|---------|
| 氨氯地平 | 5mg/日 | 10mg/日 | qd | CCB |
| 缬沙坦 | 80mg/日 | 160-320mg/日 | qd | ARB |
| 培哚普利 | 4mg/日 | 8mg/日 | qd | ACEI |

### 推荐方案
**首选：氨氯地平 5mg qd 或 缬沙坦 80mg qd**

理由：
- 患者无特殊合并症，一线药物均可选择
- CCB和ARB不良反应较少，依从性好
- 单药起始，根据血压反应调整

### 作用机制
- **CCB**：阻断L型钙通道，松弛血管平滑肌，降低外周阻力
- **ARB**：阻断血管紧张素II的AT1受体，扩张血管，抑制醛固酮

### 注意事项
- 定期监测血压（家庭血压监测）
- 生活方式干预：低盐饮食、规律运动、戒烟限酒
- 如单药控制不佳，可联合用药（CCB+ARB/ACEI）

### 避免使用
- 无特殊禁忌

### 随访建议
- 2-4周后复诊评估血压
- 目标血压：<140/90mmHg（一般人群）
```

### 示例2：2型糖尿病药物治疗

**用户输入：**
> 60岁女性，2型糖尿病，HbA1c 8.5%，合并冠心病、心衰（LVEF 35%），eGFR 55ml/min。请推荐降糖方案。

**输出：**
```markdown
## 2型糖尿病药物治疗建议

### 患者特征分析
- 合并ASCVD（冠心病）+ 心力衰竭
- 肾功能轻度受损（eGFR 55）
- 需选择心血管获益药物

### 推荐方案（优先考虑心肾获益）

| 优先级 | 药物名称 | 剂量 | 频次 | 心血管获益 |
|-------|---------|------|------|-----------|
| 1 | 二甲双胍 | 500mg起始 | bid | 中性 |
| 2 | 达格列净 | 10mg | qd | 心衰住院↓、心血管死亡↓ |
| 3 | 利拉鲁肽 | 0.6mg起始 | qd sc | MACE↓ |

### 具体方案
**推荐：二甲双胍 500mg bid + 达格列净 10mg qd**

理由：
- SGLT2抑制剂（达格列净）是心衰合并糖尿病的首选
- DAPA-HF研究证实心衰住院和心血管死亡风险降低
- eGFR 55可安全使用SGLT2i

### 作用机制
- **二甲双胍**：激活AMPK，减少肝糖输出，改善胰岛素敏感性
- **SGLT2i**：抑制近端肾小管SGLT2，促进尿糖排泄，改善血流动力学

### 禁忌症与注意事项
- 二甲双胍：eGFR<30禁用（当前可使用）
- SGLT2i：注意泌尿生殖道感染，罕见DKA风险

### 监测指标
- HbA1c（每3-6月）
- 肾功能（每3月）
- 血糖（定期监测，防低血糖）
- 体重

### 避免使用
- 磺脲类：低血糖风险高，心血管安全性存疑
- 噻唑烷二酮类：加重心衰，禁用
```

## 注意事项

1. **用药安全**：所有用药建议需由执业医师确认后方可使用
2. **个体化原则**：药物选择需结合患者具体情况
3. **监测随访**：用药期间需定期监测疗效和不良反应
4. **知情同意**：重要用药决策需与患者充分沟通
