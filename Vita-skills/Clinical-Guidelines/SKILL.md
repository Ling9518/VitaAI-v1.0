# 临床指南技能 (Clinical Guidelines Skill)

## 概述

本技能提供权威临床指南的检索和解读功能，涵盖36+部国际和国内临床指南。帮助临床医生快速获取指南核心推荐、更新要点和临床实践建议。

**数据来源：**
- ESC（欧洲心脏病学会）指南
- AHA/ACC（美国心脏协会/美国心脏病学会）指南
- WHO指南
- 中华医学会各专科指南
- NICE（英国国家卫生与临床优化研究所）指南

## 核心能力

- **指南检索**：按疾病或专科检索相关临床指南
- **核心推荐**：提取指南核心推荐要点
- **更新对比**：对比新旧版本指南的更新内容
- **证据等级**：标注推荐强度和证据质量
- **临床路径**：提供标准化诊疗流程
- **指南解读**：解读指南要点和临床应用

## 工作流程

### 步骤1：明确指南需求

当用户请求指南信息时，明确：

- **目标疾病**：需要查阅指南的疾病名称
- **指南类型**：诊断指南/治疗指南/管理指南
- **地区偏好**：国际指南/中国指南/比较
- **具体问题**：特定临床问题的推荐

### 步骤2：检索相关指南

从 `data/guidelines-database.json` 检索相关指南：

```json
{
  "指南名称": "ESC高血压管理指南",
  "发布机构": "欧洲心脏病学会（ESC）",
  "最新版本": "2024",
  "涵盖疾病": ["高血压"],
  "核心推荐": [
    "强调早期干预和个体化治疗目标",
    "推荐初始双联治疗（ACEI/ARB+CCB）",
    "强化降压目标（多数患者<130/80mmHg）"
  ],
  "证据等级": "I/A"
}
```

### 步骤3：提取核心推荐

按证据等级组织推荐内容：

| 推荐强度 | 含义 | 表述 |
|---------|------|------|
| I | 强推荐 | 推荐/应当 |
| IIa | 中等推荐 | 建议/可以考虑 |
| IIb | 弱推荐 | 可以考虑/可能有用 |
| III | 不推荐 | 不建议/可能有害 |

| 证据质量 | 含义 |
|---------|------|
| A | 多项RCT或Meta分析 |
| B | 单项RCT或大型非RCT |
| C | 专家共识或小型研究 |

### 步骤4：输出指南摘要

输出结构化指南信息：

```markdown
## [指南名称] ([发布年份])

### 发布机构
[机构名称]

### 核心推荐

#### 推荐要点1 [I/A]
[推荐内容]

#### 推荐要点2 [IIa/B]
[推荐内容]

### 更新要点（与上一版比较）
- [更新1]
- [更新2]

### 临床应用建议
[具体应用指导]

### 参考链接
- [原文链接]
- [解读文章]
```

## 常用指南核心推荐

### ESC 2024 高血压管理指南

```markdown
## 核心推荐

### 诊断标准 [I/A]
- 诊室血压 ≥140/90 mmHg 诊断高血压
- 推荐家庭血压监测和动态血压监测确诊

### 治疗目标 [I/A]
- 多数患者目标血压 <130/80 mmHg
- 老年患者可放宽至 <140/90 mmHg

### 药物治疗 [I/A]
- 推荐初始双联治疗：ACEI/ARB + CCB
- 三联治疗：ACEI/ARB + CCB + 利尿剂
- 难治性高血压：加用螺内酯

### 生活方式干预 [I/A]
- 限盐：<5g/日
- DASH饮食
- 规律运动：每周≥150分钟
- 限酒、戒烟、减重
```

### ESC 2023 心力衰竭指南

```markdown
## 核心推荐

### HFrEF药物治疗（四联疗法）[I/A]
1. ARNI（沙库巴曲缬沙坦）- 替代ACEI/ARB
2. β受体阻滞剂（比索洛尔/卡维地洛）
3. MRA（螺内酯/依普利酮）
4. SGLT2抑制剂（达格列净/恩格列净）

### 射血分数改善的心衰（HFimpEF）[I]
- LVEF改善至>40%且较基线提升≥10%
- 继续GDMT治疗

### 射血分数轻度降低的心衰（HFmrEF）[IIa]
- 考虑使用SGLT2i
- 考虑使用ARNI/ACEI/ARB、β受体阻滞剂、MRA

### 射血分数保留的心衰（HFpEF）[IIa]
- SGLT2i显示获益
- 治疗合并症（高血压、房颤、CAD）
```

### ADA 2025 糖尿病诊疗标准

```markdown
## 核心推荐

### 血糖目标 [I/A]
- 多数成人：HbA1c <7%
- 个体化目标（考虑年龄、合并症、预期寿命）

### 药物治疗路径 [I/A]
1. 一线：二甲双胍 + 生活方式干预
2. 合并ASCVD/心衰/CKD：首选SGLT2i或GLP-1RA
3. 需要进一步降糖：联合其他药物

### 心血管风险管理 [I/A]
- 合并ASCVD：使用他汀类、ACEI/ARB
- 血压目标：<130/80 mmHg
- 阿司匹林用于二级预防

### 肾病管理 [I/A]
- 每年筛查尿白蛋白和eGFR
- 合并CKD：首选SGLT2i
- ACEI/ARB用于蛋白尿
```

### GINA 2025 哮喘管理指南

```markdown
## 核心推荐

### 哮喘定义
- 气道慢性炎症 + 可变气流受限
- 症状：喘息、呼吸困难、胸闷、咳嗽

### 控制评估
- 哮喘控制测试（ACT）
- 未来风险评估

### 药物治疗

#### 成人和青少年
- 首选：ICS-福莫特罗作为维持和缓解治疗（MART方案）
- 替代：ICS + 按需SABA

#### 阶梯治疗
- Step 1-2：按需ICS-福莫特罗
- Step 3：低剂量ICS-福莫特罗 bid
- Step 4：中等剂量ICS-福莫特罗 bid
- Step 5：转诊专家，考虑生物制剂

### 急性发作处理
- 重复SABA + 早期口服激素
- 严重发作：全身激素 + 考虑MgSO4
```

## 使用示例

### 示例1：查询高血压指南

**用户输入：**
> 请提供ESC高血压管理指南2024的核心推荐

**输出：**
```markdown
## ESC高血压管理指南 2024

### 发布机构
欧洲心脏病学会（ESC）

### 核心推荐

#### 1. 高血压诊断 [I/A]
- 诊室血压 ≥140/90 mmHg 可诊断高血压
- 确诊需家庭血压监测或24小时动态血压

#### 2. 血压目标 [I/A]
- 多数患者：<130/80 mmHg
- 老年/虚弱患者：<140/90 mmHg（个体化）

#### 3. 初始药物治疗 [I/A]
- 推荐双联起始：ACEI/ARB + CCB
- 单药治疗仅适用于低危、血压轻度升高

#### 4. 难治性高血压 [I]
- 定义：三联最大耐受剂量仍未达标
- 加用螺内酯 25-50mg/日

#### 5. 生活方式干预 [I]
- 限盐（<5g/日）
- DASH饮食
- 规律运动（≥150分钟/周）
- 限酒、戒烟、减重

### 与2023版比较
- 降压目标进一步强化（<130/80）
- 更强调初始双联治疗
- 新增药物依从性评估章节
```

### 示例2：比较中外指南差异

**用户输入：**
> 比较ESC和中国高血压指南在降压目标上的差异

**输出：**
```markdown
## 降压目标指南比较

### ESC 2024 高血压指南
- 一般人群：<130/80 mmHg
- 老年患者：可放宽至 <140/90 mmHg
- 糖尿病患者：<130/80 mmHg

### 中国高血压防治指南 2024
- 一般人群：<140/90 mmHg
- 老年患者（≥65岁）：<150/90 mmHg（可接受）
- 糖尿病/CKD：<130/80 mmHg

### 差异分析
| 项目 | ESC 2024 | 中国 2024 |
|-----|---------|----------|
| 一般目标 | <130/80 | <140/90 |
| 老年目标 | <140/90 | <150/90 |
| 证据基础 | SPRINT研究 | 中国人群数据 |

### 临床建议
- 中国患者可参照中国指南目标
- 高危患者可考虑更严格控制
- 个体化考量，避免过度降压
```

## 注意事项

1. **指南时效性**：注意指南发布时间，优先使用最新版本
2. **地区差异**：国际指南与中国指南可能存在差异，需结合国情
3. **个体化应用**：指南为群体证据，需个体化应用于具体患者
4. **证据局限**：注意推荐等级，低证据推荐需谨慎
