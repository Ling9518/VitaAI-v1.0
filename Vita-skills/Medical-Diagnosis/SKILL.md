# 医学诊断技能 (Medical Diagnosis Skill)

## 概述

本技能提供基于症状和体征的智能诊断辅助功能，涵盖13个系统分类、90+种常见疾病。通过分析患者主诉、现病史、既往史等信息，提供鉴别诊断思路、诊断标准和必要检查建议。

**数据来源：**
- ICD-11国际疾病分类编码
- Medscape临床决策支持系统
- WHO疾病诊断指南
- 中华医学会各专科指南

## 核心能力

- **症状分析**：基于主诉进行症状鉴别和关联分析
- **鉴别诊断**：提供多维度鉴别诊断列表及优先级排序
- **诊断标准**：提供疾病的诊断标准和诊断依据
- **检查建议**：推荐必要的实验室检查、影像学检查
- **疾病概述**：提供疾病的病因、病理、流行病学信息
- **系统分类**：按心血管、内分泌、消化、呼吸等系统分类检索

## 工作流程

### 步骤1：信息收集

当用户描述症状或请求诊断分析时，收集以下信息：

- **主诉**：患者主要症状及持续时间
- **现病史**：症状特点、诱因、加重/缓解因素
- **既往史**：既往疾病史、手术史、过敏史
- **个人史**：吸烟、饮酒、职业暴露等
- **家族史**：家族遗传病史
- **体格检查**：生命体征及阳性体征

### 步骤2：症状分析与鉴别

根据主诉进行症状分析，参考 `references/symptom-analysis.md` 中的症状-疾病映射表：

```
常见主诉 → 可能疾病列表

胸痛 → 心绞痛、心肌梗死、主动脉夹层、肺栓塞、气胸、食管反流
呼吸困难 → 心力衰竭、肺炎、COPD急性加重、哮喘、肺栓塞
头痛 → 偏头痛、紧张性头痛、丛集性头痛、蛛网膜下腔出血、高血压
腹痛 → 急性阑尾炎、胆囊炎、消化性溃疡、肠梗阻、胰腺炎
发热 → 感染性疾病、自身免疫病、恶性肿瘤、药物热
```

### 步骤3：诊断推理

基于收集的信息进行诊断推理：

1. **概率排序**：根据发病率、年龄、危险因素调整疾病概率
2. **危险分层**：识别急危重症（红旗征）
3. **鉴别要点**：提供关键鉴别诊断要点

### 步骤4：诊断建议输出

输出结构化诊断建议：

```markdown
## 诊断分析

### 初步诊断
[最可能的诊断]（置信度：高/中/低）

### 鉴别诊断
1. [疾病A] - 支持点：...；不支持点：...
2. [疾病B] - 支持点：...；不支持点：...
3. [疾病C] - 支持点：...；不支持点：...

### 诊断依据
- [依据1]
- [依据2]

### 建议检查
- 实验室检查：[血常规、生化、心肌标志物等]
- 影像学检查：[X线、CT、超声、MRI等]
- 特殊检查：[心电图、内镜等]

### 紧急程度
[急诊/急诊观察/门诊/择期]

### 注意事项
[重要提示和随访建议]
```

## 红旗征识别

以下情况需立即识别并提示紧急处理：

### 心血管红旗征
- 胸痛伴出汗、放射痛 → 急性心肌梗死
- 突发撕裂样胸背痛 → 主动脉夹层
- 呼吸困难+低血压+颈静脉怒张 → 心脏压塞

### 神经系统红旗征
- 突发剧烈头痛（雷击样）→ 蛛网膜下腔出血
- 进行性意识障碍 → 脑疝风险
- 突发偏瘫+言语障碍 → 急性脑卒中

### 呼吸系统红旗征
- 突发呼吸困难+胸痛+低氧 → 肺栓塞
- 张力性气胸征象 → 急需穿刺减压

### 消化系统红旗征
- 腹膜刺激征 → 急腹症
- 呕血/黑便 → 上消化道出血

## 使用示例

### 示例1：胸痛诊断

**用户输入：**
> 患者65岁男性，突发胸骨后压榨样疼痛2小时，伴出汗，向左肩放射。既往高血压病史10年。

**诊断输出：**
```markdown
## 诊断分析

### 红旗征识别 ⚠️
- 胸痛伴出汗、放射痛 → 高度怀疑急性冠脉综合征

### 初步诊断
**急性心肌梗死（STEMI可能）**（置信度：高）

### 鉴别诊断
1. 急性心肌梗死 - 支持点：典型症状、危险因素；不支持点：待心电图确认
2. 主动脉夹层 - 支持点：突发胸痛；不支持点：疼痛性质不符
3. 不稳定型心绞痛 - 支持点：胸痛特点；不支持点：持续时间较长

### 建议检查（紧急）
- 心电图（立即，10分钟内）
- 心肌标志物（cTnI/cTnT）
- D-二聚体
- 床旁超声心动图

### 处理建议
1. 立即呼叫急诊/心内科
2. 阿司匹林 300mg 嚼服
3. 建立静脉通路
4. 持续心电监护
5. 准备急诊PCI或溶栓
```

### 示例2：呼吸困难鉴别

**用户输入：**
> 患者72岁女性，呼吸困难3天，伴双下肢水肿，夜间不能平卧。既往高血压、糖尿病。

**诊断输出：**
```markdown
## 诊断分析

### 初步诊断
**心力衰竭（急性失代偿）**（置信度：高）

### 诊断依据
- 呼吸困难+端坐呼吸+下肢水肿（心衰三联征）
- 高龄+心血管危险因素
- 符合Framingham心衰诊断标准

### 心功能评估
- NYHA分级：IV级（不能平卧）
- Forrester分级：需结合血流动力学

### 鉴别诊断
1. 心力衰竭 - 支持：典型症状体征
2. 肺栓塞 - 需排除：D-二聚体、CTPA
3. 肺炎 - 需排除：胸部影像学

### 建议检查
- BNP/NT-proBNP
- 心电图
- 胸部X线
- 超声心动图（LVEF评估）
- 电解质、肾功能

### 紧急程度
**急诊观察** - 需密切监护
```

## 注意事项

1. **诊断局限性**：本技能为辅助诊断工具，不能替代医生的临床判断
2. **法律声明**：所有诊断建议仅供参考，最终诊断需由执业医师确认
3. **数据更新**：医学知识库定期更新，参照最新临床指南
4. **个体化考量**：诊断需结合患者具体情况，注意个体差异
